# qp —— 运行说明

## 怎么跑

1. 把整个 `qp-0.1.0-win64` 文件夹解压到任意位置（**整个文件夹**，不要只拿 exe 出来）
2. 双击 `qp_shell.exe`

不需要安装任何东西：Qt 的 DLL、C++ 运行库、平台插件都在这个文件夹里。
不需要管理员权限，不需要联网。

## 要求

- **64 位 Windows**（10 或 11 都可以）
- 无需安装 Qt，无需安装 Visual C++ 可再发行包

## 这是什么

一个物理实验仿真平台的**界面骨架**，目前处于早期开发阶段。

打开后你会看到：

- **左侧**：节点类型列表。**双击**某一项就往图里加一个节点。
- **中间**：节点编辑器。节点可以拖动，连线会画出来。滚轮缩放，空白处拖动平移。
- **右侧**：属性面板。**点中一个节点**，它就显示那个节点的参数。
- **底部**：状态栏。显示节点数、边数、图版本、变更次数、能否撤销、运行次数，
  以及这次运行**还缺哪些可复现性输入**。

## 现在能做什么、还不能做什么

**能：**

- 加节点、拖动、选中看参数
- 改参数（数字框、下拉框、勾选框按端口类型自动选择）
- 撤销（内部已接通，只是还没接 UI 按钮）

**还不能 —— 这些不是 bug，是尚未实现：**

- **没有求值**。改参数不会让任何东西"动起来"。物理内核（Boris、蛙跳、RK4、Verlet）
  按设计是插件，还没写。
- **没有数据记录与不确定度**。`runtime/store` 里的数据结构在，但还没有测量流程。
- **不能存盘/读盘**。序列化按设计也是插件。
- **没有搜索、对齐、撤销按钮**这些编辑便利功能。

界面上能看到的东西都读过一遍路径：状态栏的数字全部来自核心，不是写死的。
所以"没有求值"这件事在界面上是看得出来的——参数改了，节点数、图版本、变更次数会变，
但没有任何计算结果，因为还没有计算。

## 崩溃或打不开怎么办

**报"找不到 Qt6Widgets.dll"之类**：说明只复制了 exe，没有复制整个文件夹。
DLL 和 exe 必须在同一层。

**双击没反应**：在文件夹里按住 Shift 右键 → "在此处打开 PowerShell 窗口"，
然后输入 `.\qp_shell.exe`，这样能看到错误信息。
