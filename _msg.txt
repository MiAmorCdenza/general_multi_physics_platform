build(package): ship a self-contained folder, and bundle the C++ runtime

The package now needs nothing from the target machine: Qt's DLLs, the platform
plugins and the C++ runtime are all inside it, so a recipient unzips and runs.

## Why the C++ runtime is copied rather than installed

`dumpbin /dependents` shows MSVCP140.dll, VCRUNTIME140.dll and VCRUNTIME140_1.dll.
Without them the program does not start at all on a machine that has never had a
Visual C++ Redistributable, and the error names a missing DLL rather than the
package that failed to supply it. Most Windows machines happen to have one because
other software installs it -- which is exactly what makes relying on it a bad bet
for a folder handed to a colleague.

`windeployqt --compiler-runtime` was the obvious answer and is the wrong one: it
deploys vc_redist.x64.exe, which the recipient must run with administrator rights
and often reboot for, and it also drags in dxcompiler.dll and dxil.dll (15 MB) for
DirectX shader compilation that a Qt Widgets application never performs. So the
three runtime DLLs are copied app-local from the MSVC redistributable directory --
Microsoft's supported pattern, no admin rights, no reboot -- and the installer and
shader DLLs are removed. Roughly 30 MB smaller and one fewer step for the
recipient.

## The run instructions travel with the package

packaging/运行说明.md is copied in by the script. Whoever receives the folder will
not have this conversation, and the file says plainly what the program can and
cannot do -- including that nothing evaluates yet, because the physics kernels are
plugins and are not written. A first-time user who reads that will not report a
missing feature as a bug.

## Two notes from finishing this

A gate can be blind to the absence of the right thing. An earlier patch of
package.ps1 went through an ASCII-encoded script and turned the Chinese in two
lines into question marks. gate.dialect saw nothing wrong, because the result is
pure ASCII -- D2 checks for the presence of the wrong thing, not the absence of the
right one. Found by eye, repaired, and worth remembering when trusting a green
gate.

Verified the way the target machine will experience it: the packaged executable
starts and renders with **both** Qt's bin directory and the VC redistributable
directory removed from PATH, so nothing from this machine can be borrowed.
